# Auftragsbuch

So geht es:
- Schreibe unten **eine Zeile pro Auftrag**.
- Schreibe danach `/do` in eine eigene Zeile.
- Schreibe im Chat `/todo-read`. Dann mache ich alles bis zum neuen `/do`.
- Wenn eine Zeile fertig ist, steht `[Fertig]` dahinter. Bei Fragen steht `[Frage: …]` dahinter.
- Ohne `/do` ist es nur ein Entwurf. Dann mache ich nichts.
